# 마음씨앗 우체국 제품 요약

만 3~5세 유아가 이모지·그림·음성으로 마음을 표현하고 균형 있게 연결된 친구 및 스스로 떠올린 친구에게 마음을 전하는 학급용 웹앱이다. 교사는 감정이나 관계를 점수화하지 않고 활동 안의 객관적 기록만 관찰한다.

## MVP 흐름
교사 로그인 → 학급 선택 → 유아모드 → 유아 선택 → 오늘 마음 → 마음친구 → 자연 마음 → 교사 관계지도. 학급별 활성 유아 2~25명을 동적으로 처리하며 유아에게 수량, 순위, 비교, 관계 점수를 보여주지 않는다.

## Demo Mode
Supabase 없이 햇님반 15명, 별님반 22명, 새싹반 25명으로 핵심 흐름을 검증한다. 모든 인물은 가상 데이터다.
